## Pingly 0.1.16

- Android pairing approval is tied to the current request.
- Turning off shared folders ends transfers from those folders. Ordinary file sharing remains available when enabled.
- Clipboard updates check that the paired session is still active.
- Download the Android APK and Linux x86_64 package together in the packages ZIP, or use the individual signed downloads.

Linux uses the existing host runtime dependencies. Android upgrades use the existing release signing identity.
